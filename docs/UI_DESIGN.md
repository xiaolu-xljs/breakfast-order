## 一、商家后台（Web 网页）

### 1.1 技术与基础信息

- **形态**：单页应用（SPA），电脑/手机浏览器打开
- **技术**：Vue 3 + Element Plus + Vite + Axios
- **地址**：部署后是 `https://admin.xxx.com`，本地开发 `http://localhost:5173`
- **入口**：必须先登录，登录态保存在浏览器 localStorage

### 1.2 整体框架

```
┌────────────────────────────────────────────────────────┐
│ ☰ 早餐店管理后台                       👤 店主 · 退出登录 │
├──────────┬─────────────────────────────────────────────┤
│ 📊 数据概览 │                                          │
│ 📋 订单管理 │                                          │
│ 🍱 菜单分类 │            主内容区                       │
│ 🥟 商品管理 │   （根据左侧菜单切换不同页面）              │
│ 🪑 餐桌管理 │                                          │
│ 📈 营业统计 │                                          │
│          │                                          │
└──────────┴─────────────────────────────────────────────┘
```

- **左侧导航**：固定菜单，可折叠（手机端自动收起成汉堡按钮）
- **顶部条**：店名 + 当前用户 + 退出登录
- **主内容区**：根据导航切换

### 1.3 页面清单

| 路径 | 页面 | 主要功能 |
|---|---|---|
| `/login` | 登录页 | 账号密码登录 |
| `/` | 数据概览 | 今日关键指标 + 待处理订单速览 |
| `/orders` | 订单管理 | 实时订单列表 + 状态切换 + 提醒 |
| `/categories` | 分类管理 | 增/删/改/排序/启停 |
| `/products` | 商品管理 | 增/删/改/上下架/上传图片 |
| `/tables` | 餐桌管理 | 增/删/二维码生成（阶段 6） |
| `/stats` | 营业统计 | 订单数、营业额、热销 TOP |

## 二、顾客小程序（WeChat Mini Program）

### 2.1 技术与基础信息

- **形态**：微信小程序，原生开发
- **入口**：扫餐桌二维码 → 自动进入小程序「菜单页」+ 自动带入桌号
- **二维码内容**：`pages/menu/menu?table=A01`（开发期是这种本地路径；上线用正式 URL）
- **登录**：静默获取 openid（后端用 code 换），无需用户操作

### 2.2 页面清单

| 路径 | 页面 | 主要功能 |
|---|---|---|
| `pages/menu/menu` | 菜单页 | 扫码落地页，看菜单、加购物车 |
| `pages/cart/cart` | 购物车 | 弹层/独立页，编辑数量 |
| `pages/order-confirm/order-confirm` | 订单确认 | 显示桌号、商品、总价，提交 |
| `pages/pay/pay` | 支付页 | 调起微信支付（阶段 5） |
| `pages/order-status/order-status` | 订单状态 | 实时显示订单进度 |
| `pages/order-list/order-list` | 我的订单 | 历史订单（可选） |

## 三、两端联调路径

```
[顾客小程序]  --HTTP-->  [后端 API]  <--HTTP--  [商家后台]
   菜单查询                  \/                    菜单管理
   下单提交                数据库                   订单接收
   状态查询                                      状态切换
```

所有数据通过阶段 1 实现的接口流转：
- 小程序用：`GET /api/categories?onlyActive=true`、`GET /api/products?onlyAvailable=true`、`POST /api/orders` 等
- 后台用：所有 `/api/admin/*` 接口（阶段 2/4 加鉴权中间件）
